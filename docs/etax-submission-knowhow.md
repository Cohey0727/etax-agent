# e-Tax（WEB版）提出の実務ノウハウ

XTXファイルを e-Tax ソフト（WEB版）から送信する際の、実際に踏んで分かったコツ集。
仕様どおりに作ったファイルでも、WEB版側の操作を間違えるとセッションが死んだり汎用エラーになったりする。

## セッション管理（最重要）

- **画面遷移は必ず画面内のボタン・リンクだけを使う。** アドレスバーにURLを直接打ち込むと `CA91 無効な操作` でセッションが即死する。ポータルTOPやマイページでも同じ。
  - 実例: 2023年分の受信通知を確認した後、マイページTOPのURLを打って CA91。申告自体は受理済みだったが、残りの提出には再ログインが必要になった。
- 戻るときもブラウザの「戻る」ではなく、画面内のリンク（メインメニュー等）を使う。
- 1件送信するごとに、即時通知の保存と受信通知の確認・保存まで済ませてから次に進む。セッションが死んでも証跡が残る。

## ファイル選択パネル（macOS）のコツ

- ファイル行をクリックしただけでは「アップロード」ボタンが有効にならないことがある。**行の「名前」セル（ファイル名のテキストフィールド）を選択状態にする**とボタンが現れる／有効になる。
- 自動操作でラベル名（「アップロード」）指定でクリックすると、無効な別コントロールを掴むことがある。要素番号で指定する。
- 一覧の並び順（追加日の昇順／降順）を切り替えると、行の要素番号が全部振り直される。並びを変えたら再観測してから操作する。
- サイドバーのネットワークボリューム等を誤って選ぶと接続待ちで固まる。キャンセルで閉じて開き直すのが早い。

## 提出フロー（1ファイルごと）

1. ポータルTOP →「申請・納付手続を行う」
2. 事前準備セットアップのダイアログ →「スキップする」（セットアップ済みの場合）
3. SE00S020 →「作成済み申告・申請データ（拡張子「.xtx」）」の「操作に進む」
4. SE00S370 → ファイル選択（上記のパネルのコツ参照）→ アップロード →「次へ」
5. SE00S380 データの表示 → 帳票にチェック →「帳票表示」→ 確認ダイアログ「はい」→ 個人番号は「印刷しない」（デフォルト）
6. 開いたPDFで数値を照合（下記チェックポイント）→ 元のタブに戻って「次へ」
7. SE00S270 → 内容（手続き名称・氏名・提出先税務署）を確認 →「送信」→ 確認ダイアログ「はい」
8. SE00S340 即時通知 → 受付番号と「エラー情報なし」を確認 →「保存」（Safariのダウンロード許可はドメインごとに初回だけ聞かれる）
9. 「受信通知の確認」→ 受信通知ページで「保存する（XML形式）」

## 送信前の数値照合（帳票PDF）

送信ボタンを押す前に、帳票PDFで次を必ず照合する。

- 事業所得・不動産所得・雑所得・合計所得金額
- 申告納税額
- 修正申告の場合: 修正前の申告納税額と差額（増加額／還付の減額）

受信通知の判定:

- 「送信されたデータを受け付けました」＋ 通知情報なし ＝ クリーン受理
- 即時通知に受付番号が出て「エラー情報なし」なら送信自体は成立している

## XTX生成仕様の要点（ジェネレータ実装の根拠）

これらを外すと `SE00S170`（サーバ側の汎用致命的エラー）になり、エラーメッセージからは原因が読めない。

- DATA要素と手続き要素は申告系ネームスペース配下に置く（所得税 = shotoku、消費税 = shohi）
- `gen:zeimusho_CD` / `gen:zeimusho_NM` は小文字の z
- IT部には `NOZEISHA_ID`（利用者識別番号）と `TETSUZUKI`（手続きコード: 所得税 RKO0010 / 消費税 RSH0010）が必須で、ITdefinition の定義順に並べる
- 手続きVR: 所得税 2023年分 → 23.1.1、2024年分 → 24.0.1、2025年分 → 25.0.1、2026年分 → 26.0.1、消費税 RSH0010 → 26.0.0
- 2026年分の様式VR（令和9年1月受付開始予定の帳票一覧で確認、2026-11-23）: KOA020=24.0、KOA210=12.0、KOA220=9.0、KOA110（収支内訳書・一般用）=13.0、KOA130（同・不動産所得用）=10.0。KOA210/KOA220 は 2023〜2025年分では据え置き（11.0/8.0）だったが 2026年分で上がる — 年分ごとの表で持つこと。
- FORM_SEC の `rdf:li` に様式IDを列挙する
- 提出前に公式XMLスキーマ（e-Tax仕様の CAB に同梱）でXSD検証を通すこと

## 環境の前提

- macOS の言語が英語だと WEB版が真っ白に描画される。**日本語環境が必須**。
- 事前準備セットアップ（Safari 拡張等）が済んでいること。
