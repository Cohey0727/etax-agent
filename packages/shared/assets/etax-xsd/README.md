# e-Tax 公式 XML スキーマ（同梱資産）

国税庁 e-Tax 仕様書一覧（https://www.e-tax.nta.go.jp/shiyo/ksk2/ksk2_shiyo3.htm）
の項番19「XMLスキーマ」（e-tax19.CAB、令和8年9月版）から取り込んだ XSD。
テスト専用フィクスチャではなく、アプリの XTX 生成時の常時検証
（packages/server/src/services/etax/xsdValidator.ts）にも使う資産として
shared パッケージの assets に置く。

全量（約5,000ファイル・73MB）は取り込まず、検証対象の手続
（shotoku/RKO0010-231・240・250、shohi/RSH0010-260・RSH0030-260）が
`schemaLocation` で参照するファイルの閉包 296 ファイルのみを保持する。

## 取得手順（申請・貸出手続きは不要）

1. 仕様書一覧ページ（上記 URL）を開く。
2. 項番19「XMLスキーマ」の「CAB形式」をクリックして e-tax19.CAB
   （約9.4MB）をダウンロードする。登録・申請・NDA は不要の公開配布。
3. CAB を展開し、「19XMLスキーマ」フォルダを取り出す。

注意: 2026-11-25 の再取得試行では、一覧ページ自体は表示できるものの
CAB 実ファイルへの GET が 404 になった（他の項番の CAB も同様）。
環境側の経路の問題かサイト側の一時的な問題かは切り分けできていない。
再取得できない場合はこの同梱版を使い続け、取得でき次第 下記の更新手順で
差し替えること。

## 更新手順

新しい仕様書 CAB を展開し、上記の手続 XSD から参照を辿って閉包を
取り直してこのフォルダへ置き換える。置き換えたら
`packages/shared/test/xtxXsd.test.ts` とサーバーの検証テスト
（`packages/server/test/xtxXsdValidation.test.ts`）を回すこと。

所得税の2026年分（RKO0010-260.xsd）は令和8年9月版に未収録
（令和9年1月受付開始分で公開予定）。公開されたら閉包に追加し、
xtxXsd.test.ts の条件分岐（ファイルがある場合のみ検証）を通常サンプルへ
寄せる。それまでの間、2026年分の XTX 生成では検証が「未同梱のため
未実施」の警告付きで続行される（無言スキップはしない）。
