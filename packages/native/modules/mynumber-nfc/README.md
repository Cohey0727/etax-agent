# mynumber-nfc（マイナンバーカード読み取りモジュール置き場）

マイナンバーカード（JPKI）の読み取りを行う Expo ネイティブモジュールの
置き場。Expo のローカルモジュールとして、このディレクトリに実装する想定。
現時点では未実装で、方針メモのみを置く。

## 想定する方式

- 通信は NFC の ISO-DEP（ISO 14443-4）上で APDU を直接送受信する。
  - Android：`NfcAdapter` の IsoDep
  - iOS：CoreNFC の ISO7816 タグ（AID は Info.plist への事前宣言が必要）
- 券面事項入力補助・署名用電子証明書の読み取りなど、用途ごとに対象の
  AP（アプリケーション）と手順が異なるため、TS 側の API は用途単位で切る。

## TS 側 API のイメージ

```ts
// 暗証番号を渡してカードと通信し、結果をバイト列で返す低レベル層と、
// 用途別の高レベル関数を分ける。
type CardSession = {
  transmit(apdu: Uint8Array): Promise<Uint8Array>;
  close(): Promise<void>;
};
```

## 注意点

- 暗証番号の連続入力ミスはカードのロックにつながる。自動リトライは
  絶対に行わない（失敗したら必ず利用者の操作を挟む）。
- iOS の NFC セッションには時間制限があるため、読み取り手順は
  セッション内で完結するよう設計する。
- 対応するカード・証明書の仕様は J-LIS（地方公共団体情報システム機構）の
  公開資料を正とする。
