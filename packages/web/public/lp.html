CONCEPT

「AI に計算させる」のではなく、
「AI が操作し、計算はエンジンが担う」

生成 AI の柔軟さと、税務計算に求められる厳密さは、役割を分けてこそ両立します。

01

決定的な計算エンジン

所得税・消費税の計算は、年度ごとの法令パラメータに基づく決定的な処理で行います。同じ入力からは必ず同じ結果が返るので、検算も再現もできます。

02

AI エージェント連携

Claude Code・Codex・Muse などの外部エージェントから API / MCP で接続できます。お使いの LLM 契約のまま、帳簿の操作や集計をエージェントに任せられます。

03

正式な手続きに沿った処理

簡易課税や各種特例、減価償却、電子帳簿保存法の訂正・削除履歴まで、正式な税務処理の要件に沿ってサポートします。

FEATURES

日々の帳簿付けから、申告データの生成まで

取り込み・分類・計算・生成をひとつの流れで。

帳簿は eTaxAgent が正本 明細の取り込みから申告まで一貫管理
  • 明細の取り込みと自動分類 銀行・カードの CSV を取り込み、AI による列マッピングとルールベースの2段階分類で仕訳を提案します。
  • 申告データ（XTX）の生成 所得税・消費税の申告データを生成し、e-Tax WEB版からそのまま提出できます。
  • 簡易課税と各種特例 簡易課税のみなし仕入率、2割特例、複数事業の75%特例に対応します。
  • 給与・年金などの所得にも対応 給与所得、公的年金等の雑所得、業務区分、所得金額調整控除まで扱えます。
  • 固定資産台帳と減価償却 定額法・定率法・一括償却・少額減価償却資産の特例に対応した台帳管理ができます。
  • 電子帳簿保存法への対応 取引の訂正・削除は履歴として残ります。証憑（レシート等）と取引の紐付けもできます。
  • 白色申告の収支内訳書 青色・白色どちらの申告にも対応します。
  • 充実したログイン保護 認証アプリによる2要素認証、マジックリンク、Google / GitHub ログインに対応します。

FAQ

よくある質問

税務相談や申告の代行はしてもらえますか？

いいえ。eTaxAgent は申告書の作成を支援するソフトウェアです。税務代理や個別の事情に基づく税務相談は行いません。申告データの提出はご本人が行ってください。判断に迷う場合は、税理士などの専門家にご相談ください。

確定申告の時期だけ使うことはできますか？

できます。月額プランはいつでも解約でき、税務シーズンだけの利用でも問題ありません。

AI エージェント連携とは何ですか？

Claude Code・Codex・Muse などの外部 AI エージェントから、API / MCP 経由で eTaxAgent の帳簿や計算エンジンを使う仕組みです。エージェントの利用には、ご自身の LLM 契約が別途必要です。

消費税の簡易課税には対応していますか？

対応しています。みなし仕入率による計算のほか、2割特例、複数事業の場合の75%特例にも対応します。

青色申告・白色申告のどちらでも使えますか？

どちらでも使えます。白色申告の収支内訳書にも対応しています。
